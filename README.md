# calculadora de media em pyton
### calcula a media entre duas notas

#### utilizado pyton 3.13.2

# como utulizar
### pra utilizar é necesario baixar o codigo e utilizar a extenção pyton no vs-code

## exemplro de uso:
``` 
## ===Sistema de Notas do Aluno===
#### digite a primeira Nota:5
#### Digite a segunda Nota:5
#### A media final è: 5.00
### status: reprovado.
```
